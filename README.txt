# KRISHNA STUDIO — VERSION 2

This is a complete responsive website with:
- Animated hero and scroll reveal effects
- Real Krishna Studio design assets supplied earlier
- Professional text-based KS brand mark plus the existing Krishna Studio logo artwork
- Services section
- Quote-based pricing section (no invented prices)
- WhatsApp order form
- Google Maps embed/search
- Mobile navigation
- Portfolio gallery
- Fast digital card printing highlight

## IMPORTANT BEFORE PUBLISHING

Open `config.js` and replace:
919999999999
with Krishna Studio's real WhatsApp number.

The pricing intentionally says "Custom Quote" because exact shop prices were not supplied. You can replace those labels with your actual prices anytime.

## FREE GITHUB PAGES

1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `config.js`, and the entire `assets` folder.
3. GitHub → repository Settings → Pages.
4. Choose Deploy from branch → main → /root → Save.
5. Open the GitHub Pages URL GitHub gives you.
